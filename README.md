# Hi, I'm awcjack

I build local-first AI systems and lightweight native apps, with a focus on
performance, privacy, and software that respects the hardware it runs on.

I'm a blockchain engineer at DeltaDeFi and work mostly with Rust, Go,
TypeScript, and Nix. I also enjoy Tauri, NixOS, distributed systems, and
reproducible development environments.

## Selected projects

- [Brian](https://github.com/use-brian/use-brian) - A local framework for agents, workflows, and documentation.
- [agentbox](https://github.com/awcjack/agentbox) - A Nix-based sandbox for running AI coding agents in isolation.
- [tmux-kube-context](https://github.com/awcjack/tmux-kube-context) - An isolated Kubernetes context for each tmux session.
- [signal-tauri](https://github.com/awcjack/signal-tauri) - A lightweight native wrapper for Signal built with Tauri.
- [DualQuickIME](https://github.com/awcjack/DualQuickIME) - A dual-mode Chinese and English keyboard for Android.
- [joplin-expenses](https://github.com/awcjack/joplin-expenses) - Personal finance management inside Joplin.
